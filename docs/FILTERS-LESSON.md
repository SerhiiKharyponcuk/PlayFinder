# Фільтри каталогу: поточна реалізація

Фільтри завершені. Навчальні маркери з коду прибрані.

## Шлях даних

1. `features/filters.js` читає дію користувача.
2. `features/catalog-state.js` перевіряє значення та записує стан у URL.
3. `pages/games.js` читає URL і викликає `gamesService.getGames()`.
4. `api/providers/rawg.js` переводить наші значення у параметри RAWG.
5. Ігри показуються відразу, потім CheapShark додає ціни через спільний кеш і чергу.
6. `selectCatalogGames()` відбирає та сортує вже завантажені ціни. Зміна цього відбору не змінює ключ запиту RAWG.

## Що підключено

Платформи, жанри, теги, магазини, один рік, релізи за останні 90 днів, майбутні релізи з оголошеною датою, пошук, сортування, діапазон цін, активні фільтри та скидання, вигляд сітка/список, пагінація й кількість карток.

Швидкі та бокові фільтри головної відкривають каталог з відповідним вибором.

Чекбокси дозволяють кілька платформ, жанрів і магазинів. Верхній список обирає одне значення у відповідній групі. Групи передаються RAWG одночасно. Жахи, кооператив та відкритий світ — теги RAWG, решта жанрів — `genres`. Рік і категорія релізу перетинаються: якщо дат немає, показуємо порожній результат без HTTP-запиту.

Замість Steam Deck використовується Linux: RAWG не має окремої платформи Steam Deck, а Linux не є підтвердженням сумісності зі Steam Deck. Ubisoft, EA і Microsoft замінені підтримуваними магазинами Xbox Store, itch.io і Google Play. ID перевірені за довідниками RAWG 04.10.2026.

Ціни й сортування за ціною діють **лише на поточній сторінці**. Ігри без підтвердженої ціни виключаються з цінового діапазону; без цінового діапазону залишаються в кінці цінового сортування. Безкоштовна пропозиція 0 USD є валідною. Поки ціни завантажуються, картки залишаються видимими.

Слайдер до 500 USD: крайнє праве положення означає відсутність верхньої межі; точну межу можна ввести числом. Порожні числові поля не обмежують ціну. Некоректні числа відсіюються, перевернуті межі впорядковуються.

Мобільні фільтри зберігаються в чернетці. «Застосувати» виконує один перехід; хрестик, Escape або фон відкидають зміни; скидання всередині панелі теж чекає застосування. Фокус утримується в панелі й повертається до кнопки після закриття.

## Ручна перевірка

RAWG повертає максимум 40 ігор за один запит, навіть якщо просити 48. Тому варіанти кількості — 12, 24, 36, 40; старе посилання `size=48` читається як 40. Пагінація рахується за фактичним підтримуваним розміром.

1. Обрати RPG та PC, перевірити адресний рядок і активні фільтри.
2. Обрати рік, оновити сторінку, перевірити відновлення значень.
3. Прибрати один активний фільтр: інші залишаються.
4. Перейти на сторінку 2; змінити жанр: сторінка скидається на 1.
5. Вибрати цінове сортування: суми впорядковані, ігри без ціни в кінці.
6. Вибрати «Безкоштовні»: показуються лише підтверджені 0 USD.
7. На телефоні змінити фільтри й закрити панель: URL не змінюється. Повторити із «Застосувати».
8. Перемкнути сітку на список; перевірити всі картки, включно з другою шісткою.

`npm run check:filters` перевіряє логіку без ключів і запитів до API. `npm run lesson:filters` залишений як сумісний псевдонім.

Джерело довідників і параметрів: [RAWG API](https://rawg.io/apidocs).
