# Як картка отримує ціну

1. Сторінка викликає `gamesService.getGames()` (одну гру — `getGame()`).
2. RAWG повертає назву, обкладинку і платформи.
3. `src/js/services/card-prices.js` шукає цю гру в CheapShark. Підходить лише один точний збіг назви (без різниці регістру, зайвих пробілів і знаків ™/®). `includes` не використовуємо: інакше можна показати ціну DLC чи іншого видання.
4. Знайдений `gameID` автоматично записується у `game.providerIds.cheapshark`. Вручну записувати його на сторінці більше не потрібно.
5. Завантажуємо поточні пропозиції, обираємо `Math.min(...)` та рахуємо унікальні магазини. Історичний мінімум `cheapestPriceEver` не є ціною, за якою можна купити зараз.
6. `components/cards.js` форматує суму та готує іконки; `templates/game-card.hbs` виводить «Від … USD», кількість магазинів і позначку PC.

CheapShark порівнює PC-магазини. Іконки показують усі платформи гри з RAWG, але ціна під ними стосується PC. Дані про консольні ціни цей API не надає.

Якщо немає однозначного збігу або пропозицій, показуємо «Немає пропозицій». Це не нуль доларів. При мережевій помилці — «Ціна тимчасово недоступна». Картка залишається доступною.

Назви між базами іноді відрізняються. Для таких ігор наступне розширення — перевірена таблиця відповідностей RAWG ID → CheapShark ID або зіставлення за Steam App ID. Не підставляйте ціну першого результату пошуку.

Кеш на 5 хвилин діє в межах відкритої сторінки. Паралельно працюють не більше трьох пошуків цін. Список магазинів спільний для всіх карток.

Де змінювати:
- логіку ціни: `src/js/services/card-prices.js`;
- запити CheapShark: `src/js/api/providers/cheapshark.js`;
- іконки: `src/js/utils/platforms.js`;
- розмітку: `src/templates/game-card.hbs`;
- стилі: `src/scss/components/_game-card.scss` та адаптив у `src/scss/layout/_responsive.scss`.

Документація джерела: https://apidocs.cheapshark.com/
