# Як картка отримує ціну

1. Сторінка викликає `gamesService.getGames()` (одну гру — `getGame()`).
2. RAWG повертає назву, обкладинку і платформи.
3. `src/js/services/card-prices.js` шукає цю гру в CheapShark. [game-matching.js](../src/js/services/game-matching.js) розгортає відомі скорочення, узгоджує цифри/римські номери та перевіряє повну назву й видання. Підходить один однозначний товар; `includes`, перший результат і видалення Deluxe/DLC не використовуємо. Якщо назва з номером не дала збігу, дозволений один кешований резервний пошук за серією, після якого перевірка повної назви повторюється.
4. Знайдений `gameID` автоматично записується у `game.providerIds.cheapshark`. Вручну записувати його на сторінці більше не потрібно.
5. Завантажуємо поточні пропозиції пакетом до 25 ID через `cheapshark-client.js`, обираємо `Math.min(...)` та рахуємо унікальні магазини. Історичний мінімум `cheapestPriceEver` не є ціною, за якою можна купити зараз.
6. `components/cards.js` форматує суму та готує іконки; `templates/game-card.hbs` виводить «Від … USD», кількість магазинів і позначку PC. Якщо товар має видання, біля ціни показуємо його назву, наприклад Enhanced.

CheapShark порівнює PC-магазини. Іконки показують усі платформи гри з RAWG, але ціна під ними стосується PC. Дані про консольні ціни цей API не надає.
Статус релізу приходить із RAWG, а не з наявності ціни. Майбутня гра може вже мати ціну: підписуємо «Пропозиція до релізу», бо CheapShark не підтверджує тип покупки (передзамовлення чи ранній доступ). Подробиці: [GAME-DETAILS.md](GAME-DETAILS.md).

Якщо немає однозначного збігу або пропозицій, показуємо «Немає пропозицій». Це не нуль доларів. При мережевій помилці — «Ціна тимчасово недоступна». Картка залишається доступною.

Назви між базами іноді відрізняються. Для таких ігор є `src/js/services/game-links.js`: додавайте перевірені пари RAWG ID → CheapShark ID. Таблиця зараз порожня, вигаданих відповідностей немає. Якщо Steam App ID вже відомий у `providerIds.steam`, він може уточнити неоднозначний результат, але не замінює перевірку назви. RAWG-адаптер зараз не отримує цей ID автоматично. Не підставляйте ціну першого результату пошуку.

### Чому не було ціни GTA V

RAWG дає `Grand Theft Auto V`, а CheapShark зараз продає базовий PC-товар під назвою `Grand Theft Auto V Enhanced` (ID 298615). Раніше ці повні назви не збігалися.
У `CURRENT_PC_TITLES` в [game-matching.js](../src/js/services/game-matching.js) є перевірений виняток тільки для GTA V. [Rockstar](https://store.rockstargames.com/en/game/buy-gta-v) підтверджує, що покупка містить повну Enhanced та Legacy.
Порядок вибору: точна база → Enhanced → Legacy. Обране видання показуємо біля ціни. Запит саме Legacy/Deluxe/Premium не підміняємо іншим виданням.
Shark Card, Premium-бандл, Starter Pack, GTA Online окремо й GTA IV не підходять. Для інших ігор Enhanced/Remastered автоматично не видаляємо.

### Приклади нормалізації

| Написання у двох джерелах | Результат |
| --- | --- |
| GTA 5 / GTAV / Grand Theft Auto V | Одна назва гри з номером 5 |
| Baldur’s Gate III / Baldur's Gate 3 / BG3 | Одна назва гри з номером 3 |
| S.T.A.L.K.E.R. 2 / STALKER 2 | Крапки абревіатури не заважають |
| Game GOTY / Game of the Year Edition | Одне GOTY-видання |
| Game / Game Standard Edition | Базове видання |
| Portal / Portal 2 / Portal 2 DLC | Різні товари |
| Game / Game Deluxe / Game Remastered | Різні товари |
| Mega Man X / Mega Man 10 | Різні ігри: X тут не римський номер |

Підзаголовки й роки зберігаємо. Незнайомі скорочення або переклади не вгадуємо.
Два різні ID з однаковим ключем означають неоднозначність, тому потрібна перевірка ID. Мінімальна ціна не допомагає обрати правильний товар.
Перевірки нормалізатора й знімок реальних назв GTA: `tests/game-matching.test.js` та `tests/fixtures/cheapshark-gta.json`; запустіть `npm test`.

Кеш у `localStorage` переживає F5, переходи між сторінками та перезапуск Vite. Пошук і магазини зберігаються на добу, ціни й знижки — на 30 хвилин. Запити послідовні, з інтервалом щонайменше 1,2 с; після 429 черга зупиняється. Недоступне API дозволяє показати ціни не старіші доби з явним підписом «Збережена ціна». Деталі та кількість запитів: [PRICE-CACHE.md](PRICE-CACHE.md).

Де змінювати:
- логіку ціни: `src/js/services/card-prices.js`;
- нормалізацію, відомі скорочення та перевірені нові PC-назви: `src/js/services/game-matching.js`;
- запити CheapShark: `src/js/api/providers/cheapshark.js`;
- іконки: `src/js/utils/platforms.js`;
- розмітку: `src/templates/game-card.hbs`;
- стилі: `src/scss/components/_game-card.scss` та адаптив у `src/scss/layout/_responsive.scss`.
