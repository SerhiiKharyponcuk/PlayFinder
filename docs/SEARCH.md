# Як працює пошук PlayFinder

Пошук підключений на головній, у каталозі та на сторінці «Про нас», у комп'ютерній і мобільній формах. Після двох символів він показує до шести підказок. Клік або вибір стрілками й Enter відкриває конкретну гру за її RAWG ID. Enter без вибору та посилання «Показати всі результати» відкривають каталог.

## Що підтримується

- Пробіли, різний регістр, апострофи, діакритика, дефіси та римські номери.
- Відомі скорочення `GTA 5`, `GTAV`, `RDR2`, `BG3`, `TW3`, `CS2`, а також скорочення з перших літер назв у локальній базі, наприклад `HL2`.
- Помилкова українська/російська розкладка: `пеф5` знаходить GTA V, `зщкефд` — Portal. Назви кирилицею також перевіряються у своїй початковій формі.
- Невеликі помилки: `Portla 2` та `Wicher3`. Такі результати позначені як «Схожа назва»; вони не обираються автоматично.
- Номери різних частин та назви видань не видаляються. Запит GTA IV не перетворюється на GTA V; Complete/Enhanced лишаються окремими варіантами.
- Неоднозначне скорочення показує кілька варіантів. Воно не переписує назву довільною грою.

Це пошук за назвою гри. Жанр, платформу та магазин потрібно вибирати фільтрами каталогу. При пошуку з каталогу вибрані фільтри зберігаються, а номер сторінки скидається до першої. Фільтри не звужують сам список підказок: вибрана підказка відкриває деталі гри, а «всі результати» враховують фільтри.

## Швидкість та запити

1. Пошук чекає 300 мс після останнього введеного символу.
2. При першому запиті завантажується локальна база з 10 000 ігор. Її індексація та пошук виконуються у Web Worker. База не завантажується при початковому відкритті сторінки.
3. Якщо локально є збіги, зовнішніх запитів для підказок немає. Обкладинки для цих записів не завантажуються — показується іконка гри.
4. Якщо збігів немає і введено щонайменше три символи, виконується один запит списку RAWG з обмеженою кількістю результатів.
5. Позитивні та порожні онлайн-відповіді кешуються на 10 хвилин, у тому числі після перезавантаження. Одночасні однакові запити спільні для обох форм.
6. Після 429 онлайн-запити призупиняються щонайменше на 5 хвилин або довше за `Retry-After`. Пауза зберігається після перезавантаження; локальний пошук залишається доступним. Інші помилки дають паузу 30 секунд.

Якщо Web Worker недоступний, пошук використовує локальну базу у звичайному JS. Якщо не вдалося завантажити й базу, лишається онлайн-пошук RAWG та звичайний перехід до каталогу.

CheapShark не викликається для підказок. Ціни отримуються вже на сторінці гри або каталогу їхньою звичайною логікою. Первинний список з 10 000 записів був отриманий один раз за 250 RAWG-запитів; користувачі його повторно з API не завантажують.

## Клавіатура та стани

- `↓` / `↑` — відкрити список та перемістити вибір. Фокус лишається в полі.
- `Enter` — відкрити вибрану гру; без вибору виконати пошук у каталозі.
- `Escape` — закрити список, зберігши введений текст.
- `Tab` або клік поза формою — закрити підказки.
- Кнопка `×` — очистити обидві форми пошуку.

Є видимий індикатор завантаження, порожній результат і повідомлення про недоступність підказок. Введення через IME не запускає пошук, доки складання символу не завершилося. Стара повільна відповідь не замінює нову; непотрібні онлайн-запити скасовуються, якщо їх не чекає інша форма.

Поля використовують `combobox`, список — `listbox`, а поточний вибір — `aria-activedescendant`, відповідно до [патерну W3C](https://www.w3.org/WAI/ARIA/apg/patterns/combobox/). Дані вставляються через DOM і `textContent`, зображення перевіряються через `safeImage`.

## Перевірка

```sh
npm run lesson:search
node --test tests/search.test.js
npm test
npm run build
```

Перша команда перевіряє 9 базових прикладів; окремі тести пошуку — базу, номери, скорочення, помилки, кеш після перезапуску, 429, спільні запити, debounce та старі відповіді. Всі ці перевірки працюють без зовнішніх API.

Результати за межами локальних 10 000 записів залежать від доступності й каталогу [RAWG](https://rawg.io/apidocs). Повні результати завжди можна відкрити через каталог. Пошук не є перекладачем довільних назв, а скорочення без однозначного збігу не підміняє іншою грою.
