# Локальний об'єкт для пошуку

Файл [search-games.js](../src/js/data/search-games.js) містить 10 000 справжніх записів із [RAWG](https://rawg.io/apidocs), вибраних за популярністю (`ordering=-added`). Це локальний знімок частини каталогу. Цін та зображень у ньому немає: для пошуку потрібні лише назва, slug та ID.

## Що імпортувати

У `src/js/features/search-query.js` шлях такий:

```js
import { SEARCH_GAMES, SEARCH_GAMES_LIST } from '../data/search-games.js';
```

- `SEARCH_GAMES` — об'єкт: ключ кожного запису є рядком із RAWG ID.
- `SEARCH_GAMES_LIST` — масив тих самих ігор. Він підходить для вашої `generateAliases(games)`, яка використовує `for...of`.

```js
const aliases = generateAliases(SEARCH_GAMES_LIST);
```

Формат окремої гри:

```js
{
  id: 3498,
  name: 'Grand Theft Auto V',
  slug: 'grand-theft-auto-v'
}
```

Пошук за ID: `SEARCH_GAMES['3498']`. Перебір усіх записів: `Object.values(SEARCH_GAMES)` або готовий `SEARCH_GAMES_LIST`. ID належать RAWG; це не `gameID` CheapShark.

Сам імпорт поки не доданий у форму: використання об'єкта та скорочень залишене вам для уроку. Файл не входить у початкову збірку сайту, доки його не імпортує код сторінки. Для майбутнього списку підказок великий модуль можна завантажити через `await import('../data/search-games.js')` лише після початку пошуку.

## Завантаження й повторне використання

```sh
npm run data:search
```

Якщо готовий файл уже містить 10 000 записів, команда завершується без запитів. Для першого отримання потрібен налаштований `VITE_RAWG_API_KEY`; читання готового об'єкта ключа не потребує. CheapShark та Firebase команда не викликає.

Кожна сторінка завантаження зберігається в ігнорованій папці `artifacts.local/search-data`. Якщо мережа або ліміт перервали завантаження, повторна команда бере отримані сторінки звідти. Помилка API зупиняє роботу; без автоматичних повторів та вигаданих записів для доповнення кількості.

[search-games.meta.json](../src/js/data/search-games.meta.json) містить дату знімка, кількість записів, сторінок, запитів останнього запуску й розмір файлу. Ключ API у дані та метадані не записується.

## Що перевірити на уроці

1. `SEARCH_GAMES_LIST.length` дорівнює `10000`.
2. В окремій грі є `id`, `name` та `slug`; назви не порожні.
3. У `generateAliases` передаємо масив, а не сам об'єкт.
4. Різні частини серії й видання залишаються різними записами з різними ID.
5. Короткі скорочення можуть збігатися в кількох ігор. Поточна `generateAliases` перезаписує однакові ключі; обробку таких збігів потрібно розібрати на уроці, перш ніж використовувати їх для автоматичного вибору гри.
