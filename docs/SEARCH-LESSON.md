# Урок: розбираємо готовий пошук

Пошук уже реалізований. [SEARCH.md](SEARCH.md) містить повне пояснення й карту файлів. На цьому уроці читаємо та перевіряємо готову логіку, без повторної реалізації всіх її частин.

## 0–10 хвилин: перевірка

1. `npm run dev`, відкрити `/PlayFinder/about.html`.
2. Ввести `GTA 5`, `HL2`, `Wicher3`, `зщкефд` та перевірити підказки.
3. Перевірити стрілки, Enter, Escape й очищення. Escape залишає текст.
4. Виконати `npm run lesson:search`: готові 9 із 9.

## 10–25 хвилин: текст і скорочення

1. Відкрити [search-query.js](../src/js/features/search-query.js).
2. Розібрати `cleanSearchQuery`, `normalizeSearchQuery` і `searchKey`.
3. Порівняти GTA IV та GTA V: цифри зберігаються, видання не видаляються.
4. Подивитися на `generateAliases`: неоднозначне скорочення не переписує назву іншою грою.

## 25–40 хвилин: список ігор та вибір

1. Відкрити [search.js](../src/js/features/search.js).
2. Знайти `show`, `select`, `hide` та обробник `submit`.
3. Простежити два сценарії: вибрана підказка → `game.html?id=...`; Enter без вибору → `games.html?q=...`.
4. Знайти `textContent`: назва з API не вставляється як HTML.
5. Перевірити мобільну форму та збереження фільтрів при пошуку з каталогу.

## 40–45 хвилин: запити та швидкість

1. [search-controller.js](../src/js/features/search-controller.js): 300 мс після останнього введення, скасування та перевірка версії відповіді.
2. [search-service.js](../src/js/services/search-service.js): локальні результати, один онлайн-запит за відсутності збігів, кеш і пауза після 429.
3. [search-worker.js](../src/js/workers/search-worker.js): робота з базою у фоновому потоці.

## 45–60 хвилин: запас на питання

Виконати `node --test tests/search.test.js`, обговорити незрозумілий файл та повторити один сценарій. Всі тести працюють без API. Якщо часу мало, достатньо розібрати форму й нормалізацію; індекс, Worker і кеш можна прочитати наступного разу.
