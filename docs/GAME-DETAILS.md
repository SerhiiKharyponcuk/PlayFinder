# Реліз гри та відкрита картка

## Звідки знаємо, що гра ще не вийшла

[RAWG](https://rawg.io/apidocs) уже повертає `released` (дата) і `tba` (To Be Announced) у відповіді списку/деталей. Новий окремий запит для кожної картки не потрібен.
[rawg.js](../src/js/api/providers/rawg.js) записує їх як `releaseDate` і `releaseTba`.
[release.js](../src/js/utils/release.js) обчислює статус при кожному показі:

| Дані | Що показуємо |
| --- | --- |
| Дата пізніше сьогодні, tba=false | «Ще не вийшла» + очікувана дата |
| tba=true | «Ще не вийшла» + «Дату ще не оголошено»; приблизну дату не обіцяємо |
| Дата сьогодні | «Реліз сьогодні» |
| Минула дата | «Вже вийшла» |
| Немає коректної дати, tba не true | Статус невідомий; відсутність дати не означає майбутню гру |

Це загальна дата гри з RAWG, а не перевірка релізу кожного її порту/магазину. День порівнюється за календарем браузера; український підпис дати не зсувається через UTC. Некоректні значення на кшталт 30 лютого відкидаємо.
На картці майбутньої гри є бейдж. Якщо CheapShark уже має пропозицію, позначаємо її «Пропозиція до релізу». Це може бути передзамовлення чи ранній доступ: API не підтверджує тип покупки. Наявність ціни сама по собі не означає, що гра вийшла.

## Де оформлювати відкриту картку

- [game.html](../game.html) — шапка, навігація і контейнер `#gameDetails`.
- [pages/game.js](../src/js/pages/game.js) — `gamesService.getGame(id)`, потім поточні пропозиції через `getOffers(game)`. Це той самий кеш CheapShark, без повторного пошуку назви.
- [components/game-details.js](../src/js/components/game-details.js) — підготовка даних до показу: іконки, дата, рейтинг, мінімум, магазини, безпечні URL.
- [game-detail.hbs](../src/templates/game-detail.hbs) — BEM-розмітка обкладинки, опису, фактів та цін. `{{...}}` екранує текст; `description_raw` не вставляється як HTML.
- [_game.scss](../src/scss/pages/_game.scss) — вигляд на комп’ютері, планшеті й телефоні.
- [page-animations.js](../src/js/animations/page-animations.js) — поява через GSAP; враховує `prefers-reduced-motion`.

Текст опису, жанри, рейтинг, розробник і видавець беруться з RAWG. Якщо поле порожнє, не додаємо вигадану оцінку чи компанію. Для довгого опису є робоче «Читати повний опис».
У таблиці показуємо справжні назви магазинів і їхні поточні пропозиції; перший рядок — мінімум. Якщо таблиця оновилася після summary-картки, мінімум над нею також оновлюється.
Кнопка обраного використовує наявний Firebase-модуль; для збереження потрібен налаштований Firebase і вхід.

## Перевірка

`npm test` перевіряє майбутні/невідомі дати, tba, календар, відображення пропозицій до релізу і безпечний текст.
Відкрийте каталог і натисніть назву гри. Перевірте дату, іконки, суму та рядки магазинів. Для майбутньої гри має бути окремий статус; відсутність пропозицій не повинна прибирати опис.
