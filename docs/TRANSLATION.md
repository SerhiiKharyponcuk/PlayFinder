# Українська та англійська

Мову можна вибрати в шапці будь-якої сторінки: **UA / EN**. Вибір зберігається у `localStorage` під назвою `playfinder.language`. Сторінку не потрібно перезавантажувати: поля форми, пошуковий запит, вибрані фільтри та сердечка залишаються.

## Де працювати на уроці

| Що змінювати | Файл |
| --- | --- |
| Англійські тексти | `src/js/i18n/en.js` |
| Збереження мови, числа, дати й повідомлення з кількістю ігор | `src/js/i18n/core.js` |
| Заміна тексту на сторінці та переклад нових карток | `src/js/i18n/dom.js` |
| Вигляд перемикача | `src/scss/components/_language-switch.scss` |
| Підключення перекладу перед запуском сторінки | `src/main.js` |
| Перевірки перекладу | `tests/i18n.test.js` |

## Як додати текст

Спочатку напиши український текст у HTML та познач його `data-i18n`:

```html
<h2 data-i18n>Популярні ігри</h2>
```

У `en.js` додай переклад. Зліва має бути та сама українська фраза:

```js
'Популярні ігри': 'Popular games',
```

Якщо елемент створюється через JavaScript, теж додай позначку:

```js
message.setAttribute('data-i18n', '');
message.textContent = 'Популярні ігри';
```

Для підказки в полі або доступної назви кнопки використай `data-i18n-attrs`:

```html
<input placeholder="Введи пароль" data-i18n-attrs="placeholder">
<button aria-label="Додати в обране" data-i18n-attrs="aria-label">♡</button>
```

Коли додаєш нове повідомлення з числом, наприклад «На сторінці: 12 із 20», його правило лежить у `dynamicEnglish()` у `core.js`. Не створюй окремий переклад для кожного числа.

## Ціни та дати

У шаблонах зберігається саме число, щоб при зміні мови можна було змінити формат:

```html
<strong data-i18n-price="{{price}}" data-currency="USD">{{formattedPrice}}</strong>
<time data-i18n-date="{{release.dateTime}}">{{release.dateLabel}}</time>
```

Наприклад, `19,99 USD` стає `$19.99`. Валюта та справжня сума залишаються ті самі. Дата `2 травня 2027 р.` стає `May 2, 2027`.

Переклад не викликає RAWG, CheapShark або Firebase. Він змінює позначені тексти, тому назви ігор, опис із RAWG, введений email та пошуковий запит не перекладаються автоматично. Початкові тексти зберігаються, щоб правильно повернути українську.

## Перевірка

1. Запусти `npm run dev` і перемкни UA → EN → UA.
2. Перейди на іншу сторінку: вибрана мова має залишитися.
3. Перевір пошукові підказки, поля входу й повідомлення обраного.
4. На телефоні відкрий фільтри, перемкни мову після закриття та відкрий їх знову.
5. Запусти `node --test tests/i18n.test.js`, потім `npm test` і `npm run build`.

Під час очищення прибрано невикористані HTML-шаблони, старе модальне вікно, порожні JS-модулі правових сторінок, `page-state.js` і старий переекспорт `catalog.js`. Каталог використовує `rawg.js`, а картки — спільні Handlebars-шаблони у `src/templates/`.
